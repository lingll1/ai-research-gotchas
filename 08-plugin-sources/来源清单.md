# 插件来源清单（全表）

本机三个 profile 的全部依赖条目，去重后 **81 个插件**（另有 5 个纯 npm 依赖不算插件）。

读法：

- **来源** `npm` = npm 上的公开包，按版本号可复装；`github:owner/repo` = 走 GitHub；`codeload` = GitHub tag 打包（没发 npm）；`link` = 本机目录，源码不在本仓库（见 [`../09-self-plugins/`](../09-self-plugins/) 与 [`README.md`](README.md)）
- **profile** `d` = desktop，`w` = web，`m` = mirage
- **类别** 里的「不推荐」= 能装、但空白 DSH 不必跟，理由见 [`README.md`](README.md)
- `link` 路径里的 `<root>` 指本机插件源码根目录（默认 `D:/dsh`，实际以你自己的布局为准）
