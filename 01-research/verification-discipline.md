# 验证纪律：没核实的不许写成事实

> 这条规则的成本是一次核实，收益是整篇论文的可信度。
> 违反一次，读者对你的所有数字都会打问号。

## 现象

用 AI 辅助写论文，最容易出的不是语法错误，而是**看似合理、实则不存在**的内容：

- 一条引文的作者、年份、期刊全对，但**DOI 不存在**
- 一个数值精确到小数点后三位，但**原始文献里根本没有这个数**
- 一段机制解释通顺，但**引用来源其实是另一篇文章的讨论段**
- 一个国标编号格式完美，但**它是隔壁标准的号**

这类错误比错别字危险得多，因为它们**通过了阅读者的直觉检查**。

## 根因

生成式模型擅长"补全最像真的那个"，而学术写作的容错率恰好最低。
更麻烦的是**你没法靠"读起来像不像"发现问题** —— 编造的内容通常比真实内容更流畅。

## 做法

### 一、引文逐条实测

不要问"这条文献对不对"，要问"这条文献的 DOI 能不能解析"：

```python
# 只做一件事：拿 DOI 去 Crossref 查，看有没有这条记录
import urllib.request, json

def crossref_check(doi: str) -> dict | None:
    url = f"https://api.crossref.org/works/{doi}"
    req = urllib.request.Request(url, headers={"User-Agent": "ref-check/1.0 (mailto:you@example.com)"})
    try:
        with urllib.request.urlopen(req, timeout=20) as r:
            return json.load(r)["message"]
    except Exception as e:
        print(f"[FAIL] {doi}: {type(e).__name__}: {e}")
        return None
```

**注意**：`User-Agent` 里带一个 mailto，这是 Crossref 的"礼貌池"约定，不带会受到更严的限流。

核验通过的 DOI，再去看标题、作者、年份是否与你写的一致 —— **DOI 存在不等于你理解的那篇**。

### 二、证据分级，引用前先问"这是第几级"

| 级别 | 例子 | 能支撑什么 |
|---|---|---|
| 原位实测 | 你自己测的数据、田间试验 | 可下结论（限本条件） |
| 受控实验 | 他人报道的实验结果 | 可引用结论，须注明条件 |
| 观测统计 | 大尺度监测、meta 分析 | 可引用趋势，别当机制 |
| 模型预测 | 基因组预测、模拟输出 | **只能写"预测/推测"** |
| 摘要级信息 | 只读了 abstract | 不得用于争议性论断 |

**最容易犯的错**：把模型预测写成"研究表明"。审稿人一眼能看出来。

### 三、口径必须声明，不同口径的数据不得互换

同一个物理量，不同方法给出的数值可能差一到两个数量级。**不声明口径的数值等于没有数值。**

以下是三类典型的不可互换：

**① 微生物量的三种测法**

| 方法 | 给出的量 | 单位 |
|---|---|---|
| qPCR / 基因组拷贝数 | 基因拷贝数 | copies / g |
| 高通量测序 | 相对丰度 | %（**无绝对量**） |
| 平板培养 | 可培养菌落数 | CFU / g |

这三者之间**不能直接比大小**。相对丰度升高不代表绝对数量升高 —— 分母变了结果就变。要跨方法比较，必须同时给出转换依据并注明不确定性。

**② 动力学参数：表观 Ks 不是生长型 Monod 的 Ks**

土壤/环境样品里用呼吸或矿化曲线拟合出来的半饱和常数，本质是**表观值（apparent Ks）**，混合了扩散限制、胞外酶动力学、群落异质性。
写作时必须写成「呼吸型表观 Ks」或「矿化型表观 Ks」，**不能直接与纯培养微生物的生长型 Monod Ks 并列比较**。这两者不是同一个量。

**③ 单位换算：μ 与 g 是最常错的一对**

- 比生长速率 μ 常以 `1/h` 给出，换算 `1/d` 要 **×24**
- 世代时间 g 以小时给出时，`r = ln2 / g`，得到的 r 单位是 `1/h`
- 想把 r 换成 `1/d`，同样是 ×24，**不是**把 g 换成天再算

一个 "μ = 0.05" 没写单位，读者无法判断它是 0.05/h（≈1.2/d，相当快）还是 0.05/d（很慢）。**差 24 倍。**

### 四、国标编号不凭记忆

标准号有校验规则，编一个看起来正确的号很容易。**引用前查一次原文**。

常见误传可以单独成一节来讲（见 [GB/T 9704 那篇](../03-formats/gb-t-9704-2012.md) 里的"仿宋_GB2312"），规律是：**后缀越具体、越像行业内行话，越可能是后人加的**。

### 五、列必引

参考文献表里的每一条，正文必须有对应引用位置；正文里每个 `[n]`，参考文献表必须有对应条目。

这不是格式洁癖，是两个方向的检查：

- **有表无引**：说明你可能是为了凑数粘进来的，或者删正文时忘了删
- **有引无表**：读者断链，通常是合并稿件时丢了

一条命令查前者（假设 md 里引用写成 `[12]`）：

```bash
# 把参考文献表里的编号抽出来，和正文实际引用做差集
grep -oP '^\[\d+\]' refs.md | grep -oP '\d+' | sort -n > table_ids.txt
grep -oP '\[\d+(?:,\s*\d+)*\]' paper.md | grep -oP '\d+' | sort -nu > cite_ids.txt
comm -23 table_ids.txt cite_ids.txt   # 只在表里、正文没引的
comm -13 table_ids.txt cite_ids.txt   # 只在正文、表里没有的
```

### 六、预印本必须标明

arXiv / bioRxiv / SSRN 上的内容不是"已发表"。引用时写清 `[preprint]` 并给 DOI。
**引用前再核一次是否已正式发表** —— 预印本转正后，同一个工作的结论表述常常会被改弱。

## 边界

- 这套纪律解决"不写错"，不解决"写得有说服力"。后者靠论证结构，不靠引用密度。
- 逐条核实很慢。**取舍原则**：核心论断（出现在摘要、结论、图注里的）必须逐条核，背景性引用可以放宽到"标题+期刊+年份对得上"。
- 用 AI 做核验本身也有风险：模型可能"记得"一个不存在的 DOI 并言之凿凿。**判断标准只有一个 —— 你去请求那个 URL 了吗。**
