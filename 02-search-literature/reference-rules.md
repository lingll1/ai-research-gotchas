# 参考文献：列必引，引必核

> 参考文献表不是装饰。它是读者唯一能验证你论断的通道 —— 断一条，整篇的可信度就打折。

## 现象

投稿前通读一遍，最容易漏的三类问题：

1. **参考文献表里有 3 条，正文从来没引过** —— 通常是删改正文时忘了同步
2. **正文引了 `[17]`，表里只到 `[16]`** —— 合并稿件时丢了条目
3. **格式不统一**：同一张表里作者名一会儿"张三, 李四"、一会儿"ZHANG S, LI S"；卷期有的写有的不写；DOI 有的挂链接有的纯数字

这三类问题审稿人一眼能看出来，而且会直接怀疑你的严谨性 —— **哪怕数据完全正确**。

## 根因

参考文献是全文**唯一被手工维护的交叉引用系统**（除非你用文献管理软件）。
它有两份副本（正文引用点、表里条目），而这两份副本没有强一致约束。

手改、合并、增删段落，任何一个动作都可能让两边对不上。

## 做法

### 一、双向核对（最有效的一招）

```bash
# 假设参考文献表在 refs.md，每条以 [n] 开头
grep -oP '^\s*\[\d+\]' refs.md | grep -oP '\d+' | sort -n | uniq > /tmp/table_ids.txt
grep -oP '\[\d+(?:\s*[,-]\s*\d+)*\]' paper.md \
  | grep -oP '\d+' | sort -n | uniq > /tmp/cite_ids.txt

echo "== 只在表里、正文未引（多为冗余条目） =="
comm -23 /tmp/table_ids.txt /tmp/cite_ids.txt

echo "== 只在正文、表里缺失（读者断链） =="
comm -13 /tmp/table_ids.txt /tmp/cite_ids.txt
```

**两个方向的差集都要看。** 第一种是"多"，第二种是"少"，处理方式完全不同。

如果你的引用写成 `(Author, 2023)` 这种作者-年制，把 grep 换成抓 `2023` 之类的年份 + 作者姓，思路一样。

### 二、格式统一：定一个模板，然后机械套

选定一种（GB/T 7714、APA、期刊自有格式），把**每种文献类型的模板**写成可复制的骨架：

```
期刊论文（GB/T 7714 风格）
[序号] 作者1, 作者2, 作者3, 等. 题名[J]. 刊名, 年, 卷(期): 起-止页. DOI.

专著
[序号] 作者. 书名[M]. 版次. 出版地: 出版者, 年: 起-止页.

学位论文
[序号] 作者. 题名[D]. 保存地: 保存单位, 年.

标准
[序号] 标准编号 标准名称[S]. 出版地: 出版者, 年.
```

**硬性约束**（这几条最容易出不一致）：

- 作者数量：超过 3 人时是"全部列出"还是"等 / et al."，全文统一
- 中文作者用全名还是姓名缩写，全文统一
- 卷（期）要不要都写，全文统一
- DOI 是否加 `https://doi.org/` 前缀，全文统一
- 页码写法：`123-130` 还是 `123–130`（连字符 vs 短横），全文统一
- 会议论文有没有地点与会期

### 三、每条都要能解析

**核验的最小标准**：把 DOI（或 URL）贴进浏览器，能打开到这篇文献的落地页。

```python
# 见 02-search-literature/doi-and-open-apis.md 里的 get_json()
# 拿不到 DOI 的条目（老中文文献、标准、书籍），至少核对：
#   刊名 + 年 + 卷(期) + 起止页 + 第一作者  五项
```

**没有 DOI 不等于假文献**，很多老文献、中文期刊、标准、书籍本来就没有。但这类条目**必须更严格地人工核对**，因为它们没有机器可查的锚点。

### 四、区分文献状态

| 状态 | 写法 | 注意 |
|---|---|---|
| 正式发表 | 正常引用 | — |
| 在线优先（online first） | 标 `[Epub ahead of print]` 或给 DOI | 卷期页可能还没有 |
| 预印本 | 标 `[preprint]` + 平台 + DOI | **引用前再查一次是否已正式发表** |
| 会议摘要 | 标明是 abstract | 不能当全文用 |
| 撤稿 | 明确标注 retracted | 撤稿文献引用会严重损害可信度 |

**预印本转正后结论常被改弱。** 你引的是预印本版本的强结论，正式版可能已经加了限定条件 —— 这会让你引的话不对。

### 五、中文文献的几个实务细节

- **题名与刊名照抄原文**，不要翻译、不要补副标题
- 期刊名用全称（不写"学报"缩写），除非该刊官方用缩写
- 中文文献在英文稿里引用时，常见做法是"拼音题名 + `[in Chinese]`"，具体看目标期刊要求
- 页码用中文习惯的全角还是半角，跟目标期刊

## 边界

- 用文献管理软件（Zotero / EndNote 等）能自动同步，但**软件生成的表也要人工抽检** —— 元数据来源本身可能有错（尤其从 PDF 抓出来的）。
- 双向核对只查"编号对不对得上"，不查"引的内容对不对"。后者只能人读。
- 格式统一是机械工作，但**别为了统一改掉原文信息**（比如把作者名缩写硬改成全名，容易改错）。

## 一句话记法

> **表里的每条都要在正文出现，正文的每个编号都要在表里存在。这两句话能查掉 80% 的低级错误。**
